# Bayesian-Inference-and-Data-Assimilation-for-Bivariate-Log-Price-Models
Bayesian data assimilation project using a bivariate normal model to infer unknown parameters for agricultural commodity log-prices. Implements conjugate priors and Gibbs sampling to perform posterior inference and assess convergence.
